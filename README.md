TinyURL 
Encurte links de forma rápida, simples e com um toque minimalista.

💡 Ideal para compartilhar URLs longas de forma elegante.

—

🌟 O que é?
O TinyURL é um encurtador de links leve e intuitivo. Basta colar sua URL, clicar em “Encurtar” e pronto — você recebe um link curto e funcional.

—

📦 Tecnologias Utilizadas
⚙️ Back-end: Node.js com AWS Lambda

🌐 API Gateway: Gerência das rotas shorten e redirect

🗃️ MongoDB Atlas: Armazenamento das URLs

🖥️ Front-end: HTML/CSS/JS puro

☁️ S3 + CloudFront: Hospedagem do front-end

🔐 WAF: Proteção contra abusos (rate limiting)

🔗 CORS habilitado para integração entre front e back

—

🔗 Como usar
Acesse: https://tinyurlbucket.s3-website-us-east-1.amazonaws.com

Cole o link que deseja encurtar.

Clique em “Encurtar URL”.

Copie e use seu novo link!

—

✅ Características

Design simples e responsivo

Código curto e fácil de compartilhar

Redirecionamento instantâneo

Expiração automática após 7 dias (por padrão)

—

📌 Observações

Você pode personalizar o tempo de validade da URL (em breve).

A interface traz uma referência visual à marca Track & Field apenas para fins estéticos.
